# PANBOX repository workflow

- When changing PANBOX behavior, update the affected README, architecture, API contract, examples, and Indonesian/English product guides in the same branch and pull request as the code.
- Keep the Boxsploit product page, interactive guides, and downloadable PDFs synchronized in the companion website branch and merge request. Link the two reviews when possible.
- Diagrams and claims must describe implemented behavior. Mark limited coverage and provider-specific automation explicitly.
