# PANBOX agent v0.1.0-alpha.8

This prerelease adds a clearer CI text summary for the native PANBOX agent. Logs show the release, branch and commit, gate verdict, module status, severity counts, up to ten prioritized file and line locations, and a dashboard link. GitLab can collapse the finding details; valid GitHub/GitLab CI metadata also supplies commit-pinned source links. JSON and SARIF output formats are unchanged.

VACCIN and ENETRON still use scanner engine `0.1.5` from alpha.7. The accompanying source checkout updates the dashboard with ten-row pagination, repository latest-scan timestamps, curated public remediation references, and clearer GitHub/GitLab connection controls. The agent-only release assets do not contain the dashboard; rebuild the PANBOX server Docker image from this source version to use those UI/API changes.

Pin `PANBOX_VERSION=v0.1.0-alpha.8` in CI and run `panbox version` after checksum-verified installation. Existing scans remain immutable; rerun CI for a new scan summary.
