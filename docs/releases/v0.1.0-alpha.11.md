# PANBOX v0.1.0-alpha.11

- Admin can permanently remove a revoked API or Access key record after confirmation. Active keys must be revoked first; audit events remain.
- The credentials drawer hides revoked keys by default and offers a Show revoked keys control.
- MCP setup in the dashboard and product documentation now explains where Codex/ChatGPT login happens, how to configure the local read-only bridge, and how that differs from automatic server-side review.
- The AI review panel identifies online/offline as the separate host worker's heartbeat.
- Native VACCIN/ENETRON scanner rules and CI upload behavior are unchanged from alpha.10. Agent-only and optional worker binaries remain separate release assets.
