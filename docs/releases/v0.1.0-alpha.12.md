# PANBOX v0.1.0-alpha.12

- The optional Codex host worker now starts without a ChatGPT login and waits before claiming queued reviews. Admin sees worker heartbeat and host login state separately.
- The Findings table and finding detail show AI evaluation state for the latest complete branch scan. Reviewed findings include the advisory verdict, confidence, explanation, evidence, and suggested fix. Scanner findings and gates remain unchanged.
- Dashboard and English/Indonesian guides now walk through Codex device login, local plugin installation, and ChatGPT desktop MCP setup. An ordinary dashboard redirect cannot authenticate the host Codex CLI.
- This release still uses native VACCIN/ENETRON engine `0.1.5`; CI agent scanning is unchanged from alpha.11. Agent-only and optional AI worker binaries remain separate release assets.
