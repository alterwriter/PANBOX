# PANBOX v0.1.0-alpha.9

This release adds optional server-side AI review of existing VACCIN findings. CI still runs the native agent and receives its gate immediately. When enabled by Admin, the PANBOX server uses a connected GitHub App or GitLab service account to fetch a small source window at the scanned commit, calls a configured OpenAI or Anthropic model, and stores advisory assessments plus sanitized process events. Review is off by default, capped at 1–10 findings per scan, and does not change native findings or gates.

The release assets remain **agent-only** binaries and checksum-verified installers. The VACCIN/ENETRON engine rules are unchanged from alpha.8; the agent release identifier is updated for version consistency. To use server-side review, upgrade the dashboard server from this tag (for example, pull the tag and rebuild its Docker Compose image), set the provider secret on the server, grant the SCM source-read permission, and enable review in Settings & Audit. See [server-side AI review](https://github.com/alterwriter/PANBOX/blob/v0.1.0-alpha.9/docs/ai-review.md) and the [English](https://github.com/alterwriter/PANBOX/blob/v0.1.0-alpha.9/docs/product-guide-en.md) or [Indonesian](https://github.com/alterwriter/PANBOX/blob/v0.1.0-alpha.9/docs/product-guide-id.md) guide.

This is a beta advisory review, not independent AI SAST discovery or an automated code fix. Private source snippets are sent to the selected model provider only after Admin enables review.
