# PANBOX agent v0.1.0-alpha.7

This prerelease ships the native PANBOX agent for Linux, macOS, and Windows on amd64 and arm64. It contains VACCIN engine `0.1.5` and the current ENETRON implementation. The agent-only binary, installers, archives, and `SHA256SUMS` are generated by the release workflow.

- VACCIN adds 38 tested Python and JavaScript/TypeScript signatures for direct request-controlled sinks, unsafe deserialization or execution, JWT and TLS configuration, and risky file or output operations. These rules are bounded lexical checks; they do not prove exploitability or follow taint across functions.
- Django checks cover selected settings, SQL interpolation, CSRF, redirects, and template output. Known bundled JavaScript is excluded to reduce noise.
- ENETRON records unsupported/missing dependency manifests as skipped so a completed VACCIN scan can still yield a verified result.
- The CLI now prints its release and engine versions with `panbox version`.
- The dashboard and PostgreSQL are distributed separately from the agent. Upgrade the dashboard from the corresponding repository commit before using newly added Admin SCM connections.

Pin `PANBOX_VERSION=v0.1.0-alpha.7` in CI. The installer verifies the downloaded agent against the release checksums. After installation, run `.panbox/bin/panbox version` to confirm the version. Existing dashboard scans remain immutable; run a fresh job to get results from the new engine.

This alpha has no measured precision, recall, or false-positive percentage. Review the [detection coverage guide](../detection-coverage.md) and triage findings with source context.
