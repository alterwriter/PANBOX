# PANBOX v0.1.0-alpha.10

- Added optional Codex CLI host worker for advisory server-side review using a ChatGPT login and Codex plan allowance/credits. This route does not require an OpenAI or Anthropic API key.
- Added worker heartbeat and route selection in Admin AI review settings. Existing provider API routes remain optional.
- Added a local Codex plugin package for interactive, read-only MCP inspection.
- Release assets now include standalone `panbox-ai-worker` binaries alongside the unchanged agent-only downloads.
- AI review remains beta: no independent AI discovery, automatic triage, gate changes, or measured false-positive rate.
